## GitHub Pages
1. Crear un repositorio.
2. Subir todo el contenido de esta carpeta a la raíz.
3. En GitHub: Settings → Pages → Deploy from a branch → `main` / `/root`.
4. Para el dominio final, configurar `limpiatapizados.com.ar` en Pages y luego los DNS en NIC.ar.

## Dominio
El SEO/canonical y sitemap están preparados para `https://limpiatapizados.com.ar/`.
Si finalmente el dominio principal es `limpiatapizados-srl.com.ar`, reemplazar esa URL en los 3 HTML, `robots.txt` y `sitemap.xml`.
